## 🛠️ Tools & Technologies Used

During this round, our team utilized a diverse toolkit to "peel" through the layers of each challenge:

  * **Forensics:** `Wireshark`, `tshark`, `binwalk`, `exiftool`, `steghide`
  * **Reverse Engineering:** `JADX-GUI`, `Bytecode Viewer`
  * **OSINT:** `Wayback Machine`, `GitHub Gists`, `Google Dorking`
  * **Scripting:** `Python` (NumPy, Matplotlib for Signal Processing), `Bash` (Automation)
  * **Crypto:** `John the Ripper`, `Base32/64 Decoders`
